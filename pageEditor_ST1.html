Home page

I used the shared template structure for this page so it matched the rest of the website. The page includes a header, navigation bar, main content area and footer. I also kept the same file naming and navigation structure that I shared with the group.

In the main section, I added three cards to introduce the topic. Each card has a heading, an image and a short piece of text about why life on land matters. I also added a tile section linking to the four student content pages so users can move easily through the site.

In terms of code, I used semantic HTML such as <header>, <nav>, <main>, <section> and <article>. For styling, I used the shared CSS for the overall layout and added a small embedded <style> block for home page only features such as the hero banner and home card images.

Gallery page

The gallery page follows the same shared template but includes more interaction. I created a grid of images, each with a short title and description. When the user clicks a gallery item, JavaScript opens an extended view and inserts the correct image and text.

I used JavaScript event listeners for the gallery interactions. This includes opening the modal, closing it, and allowing the user to change the colour view and font style inside the extended view only. I used data- attributes in the HTML to store the image, title and text for each item, and then used JavaScript to read that data and display it in the modal.

For the layout, I used the shared CSS grid styles and then added a few page specific styles in an embedded style block so the gallery page had its own small custom touches without breaking the global design.

Content page

My content page is based on the same shared layout, but the content is organised into clear sections with an internal side navigation. This makes it easier to move around the page and helps the user jump straight to the section they want.

I used section ids for internal linking, an <aside> for the side navigation, and a fixed Top button to return to the top of the page. The page also includes four relevant images with alt text.

I used the shared CSS to create the two column layout and then added a few small content page specific styles to highlight the introduction and make the page easier to read.

Challenges and lessons learned

One challenge was keeping the pages consistent while still making them different enough to meet the individual page requirements. I solved this by using one shared stylesheet for the main website structure and then adding page styles only where needed.

Another challenge was the gallery interaction. I wanted to make sure it was clearly done with JavaScript and not just CSS, because that is part of the marking requirements. Using event listeners and a modal helped me solve that properly.

From this, I learned that setting up the structure well at the start makes the rest of the coding much easier, especially when working as part of a group.

Accessibility

I considered accessibility by using semantic HTML, clear headings, alt text for images, readable colour contrast, and consistent navigation. I also made sure links were easy to recognise and that the top button stayed visible while scrolling.

On the gallery page, the items can also be focused, not only hovered, which helps keyboard users as well. These choices make the pages easier to use.

Compliance

The pages I created are educational and appropriate for a university website. I did not include misleading content. I also made sure that external resources such as images are acknowledged in the references section instead of being presented as my own work.

I also tried to work in an honest way by keeping the content relevant to the coursework and by acknowledging resources that helped me during development.

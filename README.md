# Life-On-Land-Website

## About the Project

This was a group project for my first-year Web Development module at the University of Westminster. We worked in a team of four to create a website based on the UN Sustainable Development Goal 15, Life on Land.

The website focuses on wildlife, biodiversity and protecting the environment. Our aim was to make it informative and easy to navigate, while using the HTML, CSS and JavaScript skills we had learnt during the module.

## Technologies Used

- HTML – For creating the structure and content of the pages
- CSS – For styling and designing the website
- JavaScript – For adding interactive features, particularly in the gallery

## My Contributions

My main responsibilities were:

- **Homepage:** Created the homepage, including the layout, images and navigation.
- **Gallery:** Developed an interactive image gallery using JavaScript, allowing users to view information about different images and customise some of the display settings.
- **Website Template:** Created the shared HTML template and CSS styling that helped keep the design consistent across everyone's pages.
- **Content Page:** Created my own page about biodiversity and wildlife.
- **Testing:** Checked my pages using HTML validation tools and fixed errors where needed.

## What I Learned

This project helped me become more confident using HTML, CSS and JavaScript together to create a working website.

I also learnt how important it is to keep code organised, especially when multiple people are working on the same website. Creating the shared template helped me understand how to maintain a consistent design across different pages.

Working in a group also improved my communication and teamwork skills, as we had to make sure our individual pages worked well together.
